  • critical

    CORS allows any origin with credentials

    Access-Control-Allow-Origin: * combined with allow-credentials lets any site read authenticated responses on behalf of a logged-in user.

    Fix: Echo back a specific allowed origin instead of a wildcard.

  • medium

    Content-Security-Policy allows 'unsafe-inline'

    'unsafe-inline' permits inline <script> and event-handler attributes, which is exactly the payload most XSS relies on.

    Fix: Move inline scripts to files, or use a per-response nonce or hash.

  • medium

    Content-Security-Policy uses a wildcard source

    A wildcard in default-src or script-src permits scripts from any host.

    Fix: List the specific origins you actually load code from.

  • medium

    No clickjacking protection

    Neither X-Frame-Options nor a CSP frame-ancestors directive is set, so the page can be framed by any site and used for clickjacking.

    Fix: Send `X-Frame-Options: DENY` or `CSP: frame-ancestors 'none'`.

  • low

    X-Content-Type-Options is not 'nosniff'

    Browsers may MIME-sniff a response and execute an uploaded file as script even though it was served as text.

    Fix: Send `X-Content-Type-Options: nosniff`.

  • low

    server header discloses server software

    server

    `server: nginx/1.18.0` tells an attacker exactly which version to look up known vulnerabilities for.

    Fix: Suppress the server header at the proxy or app server.

  • low

    x-powered-by header discloses server software

    x-powered-by

    `x-powered-by: Express` tells an attacker exactly which version to look up known vulnerabilities for.

    Fix: Suppress the x-powered-by header at the proxy or app server.

  • low

    Strict-Transport-Security max-age is short

    max-age is 3600s; browsers stop enforcing HTTPS once it expires, and preload requires at least 15552000s.

    Fix: Raise max-age to 15552000 or more.

  • low

    Referrer-Policy is missing

    Full URLs — including any tokens in the query string — leak to third-party sites in the Referer header.

    Fix: Send `Referrer-Policy: strict-origin-when-cross-origin`.

  • info

    Permissions-Policy is not set

    Camera, microphone, and geolocation stay available to embedded frames.

    Fix: Send `Permissions-Policy: camera=(), microphone=(), geolocation=()`.
