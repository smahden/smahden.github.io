02. Projects

Featured · Thesis Project

IDA — Adaptive Grade 4 Mathematics Software

A full-stack adaptive learning platform that teaches Order of Operations (PEMDAS) to Grade 4 students. IDA assesses each student's performance and uses content-based filtering to generate personalized learning paths that target their weak areas.

  • Engineered personalized learning paths with content-based filtering algorithms — an applied recommendation system.
  • Created UI/UX wireframes and interactive prototypes in Figma before development.
  • Built the front end as a component-based React (Vite) single-page application styled with Sass.
  • Deployed as a live web application where students track progress and see areas for improvement.
