03. Featured Projects

Featured · Thesis Project

IDA — Adaptive Grade 4 Mathematics Software

A full-stack adaptive learning platform that teaches Order of Operations (PEMDAS) to Grade 4 students. IDA assesses each student's performance and uses content-based filtering — an applied recommendation system — to generate personalized learning paths that target their weak areas. Designed in Figma, built as a component-based React (Vite) SPA, and deployed as a live web application where students track their progress.

  • React (Vite)
  • Sass
  • PHP
  • MySQL
  • Content-Based Filtering
  • Figma
