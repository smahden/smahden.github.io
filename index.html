🧠 ML & AI Live ↗ Code ↗

RecoLab: Content-Based Recommender

A recommendation engine written from scratch: TF-IDF vectorization, cosine similarity, user taste profiles, and ranking metrics, with no numpy and no scikit-learn, so the math is visible and tested. The browser demo recomputes the same cosine similarity in JavaScript and produces scores identical to the Python CLI. 56 tests.

🧠 ML & AI Thesis

IDA: Adaptive Mathematics Platform

My thesis: a full-stack adaptive learning platform that teaches Order of Operations to Grade 4 students. IDA assesses each student's performance and uses content-based filtering (an applied recommendation system) to generate personalized learning paths targeting their weak areas. Designed in Figma, built as a component-based React SPA.

  • React (Vite)
  • Sass
  • PHP
  • MySQL
  • Content-Based Filtering
🛡️ Cybersecurity Report ↗ Code ↗

Sentinel: Security Audit Toolkit

Defensive tooling that audits systems you control: it grades HTTP security headers A–F (flagging present-but-weak values, not just missing ones), scans a source tree for committed credentials with every value redacted, and scores password strength by entropy plus the patterns that make a strong-looking password guessable. 90 tests; exits non-zero for CI.

  • Python
  • CSP / HSTS
  • Secret scanning
  • Entropy
  • Pytest

UIKit: Accessible Components

Seven accessible components in ~400 lines of dependency-free JavaScript: a modal that traps and restores focus, tabs with roving tabindex, a combobox driven by aria-activedescendant, live-region toasts, and form validation wired through aria-describedby. 27 tests drive it with real key presses and assert where focus lands.

  • JavaScript
  • ARIA
  • Keyboard UX
  • CSS custom properties
  • Playwright

A full-stack Kanban board with native drag-and-drop, JWT authentication, and per-user boards, columns, and cards. The Express API renumbers card positions transactionally on every move, and 22 Jest + Supertest tests cover auth, ownership enforcement, and movement edge cases.

  • Node.js
  • Express
  • SQLite
  • JWT
  • Jest

A production-style backend: searchable product catalog, per-user carts with stock control, and checkout that snapshots prices into immutable order history, so later catalog edits never rewrite what a customer paid. Money is stored as integer cents. 22 pytest tests.
